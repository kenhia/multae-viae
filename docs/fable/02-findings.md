# Findings Registry

Consolidated and de-duplicated from five review streams. IDs are stable — reference them in
spec tasks (e.g. "fixes F1"). Severity: **H** = wrong behavior reachable today / data loss /
panic; **M** = degraded behavior or convention violation; **L** = hygiene.
Findings marked ✓ were hand-verified in source during this review; the rest were reported
with file:line evidence by the reviewing stream.
